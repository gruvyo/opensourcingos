# Archived development scripts

These scripts are retained as project history. They were used during early
development to scaffold or patch application files and are not part of the
supported setup process.

- `setup/` contains one-time scaffolding scripts.
- `fixes/` contains one-time repair scripts.

Some scripts contain assumptions from the original development environment and
may overwrite source files. Review a script before running it. The supported
local setup is documented in the repository's main `README.md`.
